# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/MariSeest/mpatchmonitor/security/advisories/new).
Include the affected URL or file, the steps to reproduce and the impact you observed.
You will get an answer within seven days.

## Scope

- The public MPatchMonitor site and its API
- The code in this repository (Worker, data pipeline, front end, workflows)

## Please do not

- Run denial-of-service or load tests, or try to exhaust the free-tier quotas
- Access data that is not yours, or keep it after confirming the issue
- Use social engineering or attack the accounts of the author

Automated scanners are detected and blocked automatically. If you are testing in good faith
and get blocked, mention it in your report.

## Safe harbour

Research carried out in good faith and within these rules will not be pursued, and you will be
credited in the fix if you wish.
