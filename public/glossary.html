    Glossary.

    The words used on this site, explained in one or two sentences. The small question marks next to labels lead here.

    CVE
    Common Vulnerabilities and Exposures: the public identifier of a vulnerability, such as CVE-2026-21001. Microsoft, other vendors and CSIRTs all use it.
    CVSS
    Common Vulnerability Scoring System: a 0–10 score of how serious a vulnerability is in technical terms, such as how it is reached and what it gives the attacker. It does not say whether anyone is exploiting it.
    EPSS
    Exploit Prediction Scoring System, by FIRST: the probability that a vulnerability will be exploited in the next 30 days, updated every day.
    CISA KEV
    The Known Exploited Vulnerabilities catalog of the US Cybersecurity and Infrastructure Security Agency: vulnerabilities with evidence of real attacks, each with a remediation deadline for US federal agencies.
    Zero-day
    A vulnerability that was already being exploited when the vendor released the fix. Microsoft marks it as Exploitation Detected.
    Exploited in the wild
    Attackers are using the vulnerability in real attacks, as reported by Microsoft or CISA.
    Publicly disclosed
    Details of the vulnerability were public before the fix, even if no attack is known.
    Public exploit code
    Working attack code that anyone can download: a Metasploit module, a Nuclei template or a proof of concept on GitHub. It makes attacks more likely, but it is not proof that attacks are happening.
    Exploitability index
    Microsoft's assessment of how likely exploitation is: Exploitation Detected, More Likely, Less Likely or Unlikely.
    Severity
    Microsoft's rating of a vulnerability: Critical, Important, Moderate or Low. Critical usually means code execution without any user action.
    Patch Tuesday
    The second Tuesday of every month, when Microsoft releases its security updates, at about 19:00 Italian time.
    Out-of-band update
    An update released outside Patch Tuesday, usually to fix an urgent problem.
    KB
    Knowledge Base: the number of a Microsoft update, such as KB5070112. One update fixes many CVEs.
    Cumulative update
    A Windows update that also contains every earlier fix: installing the latest one is enough.
    Supersedence
    A newer update replaces an older one. You only need to install the newest.
    Build
    The exact version of Windows or of an application, such as 10.0.26100.6584. A device is protected when its build is equal to or later than the fixed build.
    Known issue
    A problem that Microsoft has confirmed after an update is installed, often with a workaround.
    Hotpatch
    Security updates applied without restarting, on the Windows editions that support them.
    Mitigation
    A setting or condition that reduces the risk, such as a feature that is off by default, until the update is installed.
    Workaround
    A temporary change, such as blocking a port or turning off a service, that removes the attack path until you can update. It may affect how things work.
    Risk score
    MPatchMonitor's score from 0 to 100. It combines exploitation, CISA KEV, ransomware use, EPSS, CVSS, public exploit code and recent activity.
    Priority P1–P4
    The order and deadline for fixing: P1 within 7 days, P2 within 14, P3 within 30, P4 within 90. Used by My devices and the evidence report.
    Ransomware use
    CISA reports that the vulnerability is known to be used in ransomware campaigns.
    End of life
    The date after which a product no longer receives security updates. Some products offer paid Extended Security Updates (ESU) for a few more years.
    SBOM
    Software Bill of Materials: the list of components and versions inside an application. MPatchMonitor reads CycloneDX and SPDX files.
    Package URL
    A standard way to name a software package and its version, such as pkg:npm/lodash@4.17.20.
    Rollout in waves
    Installing an update on a few pilot devices first, then on the other workstations, then on servers, so a faulty update is caught early.
    NIS2
    EU Directive 2022/2555 on cybersecurity, applied in Italy by Legislative Decree 138/2024 and supervised by ACN. It requires handling vulnerabilities and keeping evidence of it.
    ACN and CSIRT Italia
    Italy's National Cybersecurity Agency and its incident response team, which publishes security bulletins.
    MCP
    Model Context Protocol: a standard that lets AI assistants query data sources. MPatchMonitor offers a read-only MCP server.
    Web push
    Browser notifications that arrive even when the site is closed. The site only stores an anonymous address created by the browser and the topics you chose.
    MITRE ATT&CK
    A public knowledge base of the techniques attackers use, each with an identifier such as T1068. Knowing the technique helps choose the right detection.
    KQL
    Kusto Query Language: the query language of Microsoft Defender XDR advanced hunting and Microsoft Sentinel. The queries on this site find the devices exposed to a vulnerability.
    Sigma rule
    A detection rule written in a common format that converts to the query language of most SIEMs, including Microsoft Sentinel and Splunk.
    Windows release health
    Microsoft's pages that list the known issues of Windows updates, their status and their workarounds.

    Data: Microsoft Security Update Guide, CISA KEV, FIRST EPSS. An independent project by Luisa Mele, not affiliated with Microsoft.
