    Which Microsoft updates are your devices missing?

    Load an inventory of your Windows devices. It is compared with every fix Microsoft published in the last twelve months, right here in your browser: your files never leave your computer.

    Run the collector

    A short, read-only PowerShell script records the Windows build, Edge and Microsoft 365 Apps versions and installed updates. It needs no admin rights and makes no network connection.

    Download collect.ps1 

    powershell -ExecutionPolicy Bypass -File .\collect.ps1 -Anonymize

    Import from Intune or Defender

    Export your device list as CSV: in Intune from Devices, All devices, Export; in Defender for Endpoint from Assets, Devices, Export. The device name and OS version columns are enough.

    Try it with sample devices

    See the analysis on six fictional devices built from the current Microsoft data: some up to date, some months behind.
